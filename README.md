# Bilim Arena Race

Образовательная многопользовательская гонка. Учитель запускает соревнование, команды
подключаются со своих устройств и продвигаются по карте, проходя учебные испытания.
Общий экран показывает карту и положение команд в реальном времени, а после финиша —
результаты и аналитику.

> Статус: **Этап 0** — фундамент проекта. Игровая механика ещё не реализована.
> Это самостоятельный проект: он не использует код, базу данных, API и авторизацию
> основного сайта Bilim Arena. Интеграция возможна только после завершения
> и тестирования standalone-версии.

## Основная идея

1. **Учитель создаёт гонку:** выбирает тему, настраивает маршрут и испытания, открывает комнату.
2. **Студенты подключаются** по коду комнаты с телефонов, планшетов или ноутбуков и
   объединяются в команды.
3. **Гонка:** на каждом чекпоинте команду ждёт испытание. Правильные и быстрые решения
   продвигают команду по карте.
4. **Общий экран** показывает карту и позиции команд в реальном времени.
5. **Финиш:** итоговая таблица и образовательная аналитика — какие темы даются легко,
   а что стоит повторить.

Все критические решения (очки, позиции, победитель, завершение гонки, награды) принимает
сервер, а не браузер. Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Planned features

- **Комнаты** — вход по коду, лобби перед стартом.
- **Команды** — создание команд и распределение участников.
- **Карта** — маршрут с чекпоинтами, общий экран с позициями команд.
- **Задания** — быстрые вопросы, задачи, программирование, исправление ошибок в коде,
  скоростная печать, сборка понятий, пазлы, командные задания.
- **Мини-игры** — отдельные интерактивные испытания на чекпоинтах.
- **Realtime** — мгновенное обновление карты и счёта у всех участников.
- **Бонусы** — ускорения и особые чекпоинты.
- **Стратегия** — выбор маршрута и момента для бонусов.
- **Результаты** — итоговая таблица и история гонки.
- **Аналитика** — разбор ответов по темам и заданиям для учителя.

## Installation

Требуется **Node.js 24+** и npm.

```bash
git clone https://github.com/akbaralievernis/bilimarena_race.git
cd bilimarena_race
npm install
cp .env.example .env.local
```

Стартовая страница работает и без Supabase. Переменные окружения нужны только коду,
который обращается к базе данных.

## Environment variables

Шаблон — [.env.example](.env.example). Реальные значения храните в `.env.local`:
этот файл исключён из Git.

| Переменная | Где используется | Описание |
| --- | --- | --- |
| `NEXT_PUBLIC_SUPABASE_URL` | браузер и сервер | URL Supabase-проекта |
| `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | браузер и сервер | Publishable key (`sb_publishable_...`) или legacy anon key. Публичный по назначению: доступ к данным защищают политики RLS |
| `SUPABASE_SECRET_KEY` | только сервер | Пока **не используется**. Понадобится только доверенному серверному коду. Никогда не добавляйте префикс `NEXT_PUBLIC_` |

Для гонки нужен **отдельный** Supabase-проект — не production-база основного Bilim Arena.

## Deployment

Проект готов к деплою на [Vercel](https://vercel.com) без дополнительной конфигурации:

1. Импортируйте репозиторий в Vercel — фреймворк Next.js определится автоматически.
2. В **Project Settings → Environment Variables** добавьте `NEXT_PUBLIC_SUPABASE_URL`
   и `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (отдельно для Production и Preview, если нужны
   разные Supabase-проекты).
3. Значения `NEXT_PUBLIC_*` встраиваются в сборку, поэтому после их изменения
   нужен повторный деплой.
4. После первого деплоя добавьте домен Vercel в **Supabase → Authentication → URL Configuration**
   (Site URL и Redirect URLs).
